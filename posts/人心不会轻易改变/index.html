    1. 日文原文#

    皆さん は 街 で アンケート 調査 の 依頼 を された ことが ある でしょう か？ 「ペンは こちらの 5本 から 選んで ください」 と 言われた とします。では、皆さん は どの ペンを 選びます か？ ここ では 単純 に 青 か 赤 か で 手を 挙げて いただきたい と思います。はい、会場 は 大体 半々か が ちょっと 多い ぐらい でした。

    今、ちょっと 言う のを 忘れて しまいました けど 早速、これら すべて 黒の ボールペン です 実は。ただ 柄 の 色 が 異なる だけ なので。ここで 注目 したい のは、青 が 2本 赤 が 3本 といった 形 で、青の ペンが 少ない 点 です。ここ では 少ない 数の ペンを 「ユニーク な ペン」 と 定義 します。では、そのような ペン を 果たして どれ くらいの 人 が 選ぶ の でしょう か？ 実は これ は 1999年 に ある 実験 が 行われて おりまして、そう した ところ、アメリカ人 の 71%が ユニーク な ペン を 選びました。一方 で アジア人 は たった 15% しか ユニーク な ペン を 選べません でした。

    個人 を 重視 する の か、それとも 関係 や 集団 を 重視 する の か、それに 関して は、実は かなり 大きな 文化 差 が ある こと が 知られて います。この ペン 選択 の 結果 は 何 を 示して いるか と いう と、その 個人 の 重視 と いう の が、いかに 自分 と 他人 と いう の を 比べ て、自分 が ユニーク なもの である か、その ユニーク さ と いう の を 重視 する 心 と 関連 している ことを 示して います。一方 で、関係 や 集団 の 重視 と いう のは、周り を 気 に する 調和 を 重視 する 心 に 関連 している と 言われます。

    2. 中文翻譯#

    大家 是否 有 过 在 街 上 遇到 别人 请求 做 调查 问卷 的 经历？ 假设 现在 有人 对 你 说： “请 从 这 五 支笔 中 选择 一 支。” 那么，你 会 选择 哪 支笔 呢？ 在 这 里，我 希望 大家 简单 地 从 颜色 进行 举手 表决 选择，蓝色 还是 红色。好 的，会 场 里 选择 的 人数 大概 是 对 半 分，红色 稍微 多 一点。

    刚刚 我 忘记 说 了，实际上 这些 全 都 是 黑色 圆珠笔，只是 笔柄 的 颜色 不 同 而已。这里 值得 注意 的 是，蓝色 笔 有 两 支，红色 笔 有 三 支，蓝色 笔 的 数量 较 少。我们 在 这 里 将 少数 的 笔 定义 为 “独特 的 笔”。那么，到底 有 多少 人 会 选择 这样 的 笔 呢？ 事实 上，这是 在 1999 年 进行 的 一 项 实 验，结果 显示，71% 的 美国人 选择 了 独特 的 笔。而 亚洲人 则 只有 15% 选择 了 独特 的 笔。

    个人 是 重视 自己 呢，还是 重视 关系 或 集体 呢？关于 这 一点，其实 是 存在 相当 大 的 文化 差异 的。这个 笔 选择 的 结果 说明 了 什么 呢？那 就 是 个人 重视 这一点，如何 比较 自己 和 他人，自己 是 独一无二 的，这 种 独特性 和 重视 自我 的 心态 是 相关 联 的。另一方面，重视 关系 或 集体，则 与 顾及 周围，重视 和谐 的 心态 相关 联。

    第 2 頁內容#

    1. 日文原文#

    人の心はそんな簡単に変わらない トのおかげで、今世界中どこの情報でも知ることができます。 ということは世界中の人々が接する情報というのは、かなり同じようなものになっています。グローバル化というのは一般的に、個人主義化というのを促すということが言われています。 しかし、今日ご紹介した研究からもわかる通り、その可能性というのはあまりないでしょう。 社会や文化の変化に応じて、私たちの心の性質というのも確かに変化はしていくのですが、その変化のスピードというのは緩やかなものです。このことは、変化を求めるような人たちからしてみたら、意外な結論かもしれないんですけど、人の心はそんなに簡単に変わらない。

    2. 中文翻譯#

    人心不会轻易改变 然而，我剛剛說明的這一點，大家听后可能會覺得：“不不不，最近的日本人，特別是年輕人，應該會更傾向於選擇獨特的筆吧。”眾所周知，隨著全球化的發展，由於互聯網的出現，我們現在可以了解到世界各地的信息。也就是說，全世界的人們接觸到的信息基本上是相似的。全球化通常被認為會促進個人主義化。然而，正如今天介紹的研究結果所表明的那樣，這種可能性并不大。 隨著社會和文化的發展變化，我們心理特征的確會發生改變，但這種變化的速度是緩慢的。對於渴望寻求改变的人來說，這可能是一個出乎意料的結論，但人類的心理並不會輕易改變。

    第 3 頁內容#

    1. 日文原文#

    人の心はそんな簡単に変わらない

    今日の話というのは、まず文化差から明らかなように、私たちというのは何もない状況の中で生きているわけでは決してありません。そして文化の中で優勢な価値観、その価値観を親世代から子世代へとつい伝えてしまう。こういったようなことからもわかる通り、私たちというのは社会文化の影響をただ受けているわけではありません。むしろ、そういったような振る舞いによって、私たちというのは、私たちが生きている社会文化を維持させていくことになっています。よって、私たちというのは社会文化を再生産する存在であると言えます。

    2. 中文翻譯#

    人心不会轻易改变

    今天的演讲，正如从文化差异中可以明显看出的那样，我们并不是在一个空白的环境中生活。同时，父母一代会将文化中占主导地位的这些价值观传承给子代。正是通过这样的行为，我们才能不仅仅是受到社会文化的影响，同时还能传承生活中的社会文化。因此，可以说我们就是社会文化再生产的存在。
